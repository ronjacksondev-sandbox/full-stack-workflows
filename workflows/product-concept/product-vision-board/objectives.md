## Project Objectives
- Design a minimal HTML Page
- Design a single column layout
- Use basic aesthetic typography and styling
- Use orange and green brand colors
- Design a dark mode option



## Learning Objectives
- Write valid semantic HTML 
- Implement classless css framework `water.css`
- Implement the `water.css` light and dark theme
- Write custom css to style `hr` orange and green
- Write unit tests to verify expectations
- Verify html passes w3c validation
- Host on GitHub Pages
