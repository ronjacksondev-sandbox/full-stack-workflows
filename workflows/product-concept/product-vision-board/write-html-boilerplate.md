## Write `html` and `head` elements

``` html
<!doctype html>
<html lang="en">
  <head>
    <meta charset="UTF-8" />
    <title>Duo Budget – Product Vision Board</title>
    <meta name="viewport" content="width=device-width, initial-scale=1.0" />
  </head>
  <body>
  </body>
</html>
```
