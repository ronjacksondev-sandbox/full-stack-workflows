## Dev Environment

- **Shell:** Bash  
- **Version Control:** Git & GitHub  
- **Unit Tests:** Node:Test, JSDOM  
- **Editor:** VS Code

## Frontend

**HTML:**
- **Semantic Outline:** `header` | `main` | `footer`
- **Headings:** `h1` | `h2`
- **Inline Text Semantics:** `em`
- **Navigation:** `a`
- **Input control:** `button`

**CSS:**
- **CSS framework:** `water.css` (classless)
- **Custom CSS:** Page level style tags

**JS:**
- **DOM manipulation:** Event handlers | Element Styles

## Backend
- **Server:** Static file server

## Infrastructure

- **Site Hosting:** GitHub Pages  
- **Deployment:** GitHub Actions
