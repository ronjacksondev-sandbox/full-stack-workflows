# Objectives

- Create a minimal HTML Page
- Single column layout
- Apply basic aesthetic typography and styling
- Integrate orange and green brand colors
- Dark mode option



## Technical Requirements
- Use valid semantic HTML 
- Apply classless css framework `water.css`
- Use the `water.css` light and dark theme
- Write custom css to style `hr` orange and green
- Write unit tests to verify expectations
- Verify html passes w3c validation
- Host on GitHub Pages
