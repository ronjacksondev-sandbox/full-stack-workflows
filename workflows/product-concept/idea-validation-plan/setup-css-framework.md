# Setup CSS Framework

## Install milligram

``` bash
npm install milligram
```

## Copy milligram to your project
``` bash
mkdir css
cp node_modules/milligram/dist/milligram.min.css css/
```

## Add `link` in page `head`
``` html
<link rel="stylesheet" href="css/milligram.min.css">
```
