## Write `body` content

``` html
<header>
  <h1>Duo Budget - Product Vision Board</h1>
</header>
<main>
  <section>
    <h2>Vision</h2>
    <p>Help people understand how <em>time</em> and <em>money</em> work together.</p>
    <p>Make clearer, more confident decisions.</p>
  </section>
</main>
<footer>
  <p>&copy; Duo Budget</p>
</footer>
```

## View page in browser
``` bash
npm run start
```
- Expectation: page should load with content visible

## Git Commit
``` bash
git add .
git commit -m 'Adds index page with html`
```
