## Setup site on Netlify
- Go to Projects
- Add new project
- Import a Git Repository > GitHub
- Authorize Netlify to access your GitHub account
- (If no repositories appear) Configure Netlify on GitHub
- Fill out deploy configuration
    - Project Name = duo-landing-page (use any name that isn't taken)
    - Branch to deploy = main
    - Leave the rest as default
    - Click Deploy
