# Deploy Page

## Merge and Push changes
``` bash
git switch main
git pull origin main
git merge feature/new-page
git push
```

## Go to cloudflare.com and login
> Build > Compute > Workers & Pages > Create Application >Create a Worker > Connect GitHub

## Walk through GitHub Authentication
> Select User or Organization

> Select All Repositories or Select Repositories

## Setup Pages

> Get Started > Import and existing Git Repository

> Select 'idea-validation-plan' > Begin setup

> Select branch 'main'

> Leave other fields blank

> Click Save and Deploy
